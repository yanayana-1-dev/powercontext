# 实验记录：bge-m3 嵌入模型批量评测

- 日期：2026-10-14
- 执行人：ricky
- 状态：已完成

## 实验目的
验证 bge-m3（1024 维）在中文工作文档语义检索上的召回表现，确认是否作为知识库默认嵌入模型。

## 实验设置
- 测试集：内部工作文档 60 篇，问题 40 条，人工标注相关段落。
- 分块：按标题分块，块长上限 600 字。
- 指标：Recall@5、MRR。

## 结果
| 配置 | Recall@5 | MRR |
|---|---|---|
| bge-m3 + 标题分块 | 0.87 | 0.71 |
| bge-m3 + 固定500字滑窗 | 0.81 | 0.64 |
| 对照：旧模型 text2vec | 0.74 | 0.55 |

## 结论
bge-m3 明显优于旧模型，标题分块优于滑窗。确认：知识库采用 bge-m3，1024 维，L2 距离 + HNSW 索引；嵌入前对文本做标题拼接增强。
