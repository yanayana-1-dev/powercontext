# 论文阅读笔记：面向 Agent 的长期记忆服务

- 阅读日期：2026-10-24
- 推荐人：ricky

## 核心观点
论文把 Agent 的记忆分为三层：工作记忆（当前对话窗口）、情景记忆（历史交互的事件）、语义记忆（从事件中沉淀的稳定事实）。作者认为工程上最重要的不是"存"，而是**沉淀（consolidation）与遗忘**：定期把零散的情景记忆合并成语义记忆，并按重要性与新鲜度淘汰。

## 与本项目的关联
1. 我们的 PowerContext 用的正是"scope + entry + revision"模型，memory entries 有状态与版本，支持 revise/retire，对应论文说的沉淀与遗忘。
2. 论文实验显示：把用户偏好单独存一类（kind=preference）并在每次会话开始时注入，任务完成率提升明显。这支持我们把偏好记忆放在检索优先级最高层。

## 可以借鉴
- 记忆条目加"置信度"字段，低置信度记忆在注入 prompt 前需要用户确认。
- 周期性 consolidate 任务：把同一主题的多条 note 合并成一条摘要。
