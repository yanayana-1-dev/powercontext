# 新人上手指南

## 第一天
- 找行政开通企业微信、OA、代码仓库权限；代码仓库权限由导师在内部系统里代提。
- 阅读本文档与《团队协作规范》，重点记住周报格式和评审响应要求。

## 第一周任务清单
1. 本地跑通主项目：按 README 完成 seekdb 与依赖服务部署，跑通一个检索示例。
2. 认领一个 good first issue（标签：good-first-issue），走完整的分支-评审-合入流程。
3. 旁听一次周会并补写会议纪要（发到团队频道），熟悉纪要格式。
4. 和导师做一次 30 分钟的一对一，明确试用期目标。

## 常用入口
- 周报提交：团队频道机器人 /weekly 命令。
- 报销相关见《差旅与报销制度》，出差前记得先提《出差申请单》。
- 遇到阻塞超过半天，直接在群里 @导师，不要自己硬扛。
