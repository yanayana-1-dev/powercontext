# SeekMem 验证样例（评审复现步骤）

前置：按 `docs/RUNBOOK.md` 完成 1-6 节（seed 已导入）。打开 `http://127.0.0.1:9100`，健康徽章四项正常（llm 显示 degraded 也算通过，只是回答形态不同）。

下面 4 组样例覆盖「seekdb 检索生效」与「PowerContext 记忆生效」两条核对线。运行后可在「证据」页签（或 evidence/*.jsonl）核对每一次 SQL 与记忆读写。

## 样例 1：混合检索找到资料并给出来源（seekdb 生效）

| 项 | 内容 |
|---|---|
| 初始数据 | 种子文档《差旅与报销制度》《新人上手指南》等 10 篇已入库 |
| 输入 | 工位填 `评审体验员`；问答页输入：`报销流程是什么？逾期提交会怎样？` |
| 操作 | 点「提问」，等待回答（本地 LLM 约 1-2 分钟，无 LLM 秒回） |

预期结果：

1. 回答内容涉及「出差申请单→OA 上传发票→财务审核」「逾期顺延/60 天不受受理」等要点，且带 `[1][2]` 来源编号。
2. 回答下方「来源」列表出现《差旅与报销制度》的多个分块，每条带通道徽章（vector=向量召回、hybrid=全文过滤+向量排序、recent=最近资料）与 l2 距离。
3. 证据核对：证据页 seekdb 查询留痕出现 3 条 SQL——`ORDER BY l2_distance(...) APPROXIMATE`（纯向量）、`WHERE MATCH(content) AGAINST(...) ORDER BY l2_distance(...) APPROXIMATE`（**单语句混合检索**，seekdb 特色）、`ORDER BY c.created_at DESC`（结构化）。

## 样例 2：告知事项 → 记忆写入 PowerContext

| 项 | 内容 |
|---|---|
| 输入 | 同一工位，输入：`记住：我们组的检索服务叫星桥，下周三要做压测第二轮，目标 P99 300ms 以内。` |
| 操作 | 点「提问」 |

预期结果：

1. 回答下方出现「已沉淀到工作记忆（PowerContext）」，带 kind 徽章（task/note 等）。
2. 切到「记忆」页签：PowerContext scope ID 显示（`scp_...`），记忆列表新增上述事项（kind=task/note）。
3. 证据核对：证据页「记忆读写留痕」出现 `memory.remember` 记录，含 entry_id（`mem_ent_...`）。

## 样例 3：跨会话记忆复用（越用越懂你）

| 项 | 内容 |
|---|---|
| 操作 | 模拟"第二天回来"：刷新页面（或新开浏览器窗口），工位仍填 `评审体验员` |
| 输入 | 问答页输入：`我下周的工作安排里压测是哪天？目标多少？` |

预期结果：

1. 回答中体现记忆内容：压测在**下周三**、目标 **P99 300ms**——这两点只存在于 PowerContext 记忆中，10 篇种子里没有（星桥周报里写的是"下周计划"不是确切日期，日期只在你样例 2 的输入里）。
2. 回答上方/下方出现「本次从 PowerContext 想起的记忆」，列出样例 2 存入的条目。
3. 证据核对：记忆读写留痕出现 `memory.search` 记录，hits 含样例 2 的记忆文本。

## 样例 4：多工位记忆隔离（scope 隔离）

| 项 | 内容 |
|---|---|
| 操作 | 工位改填 `新来的同事`（或另一个人名），重复样例 1-3 的任意一步 |
| 输入 | 问答页提问：`我们组压测什么时候？` |

预期结果：

1. 回答不包含"下周三/300ms"——新工位的 PowerContext scope 是空的，查不到评审体验员的记忆。
2. 「记忆」页签显示新 scope ID（与评审体验员不同）且列表为空。
3. 证据核对：留痕中出现两个不同 scope_id 的记录。

## 一键复跑

```bash
python scripts/verify_demo.py
```

对运行中的服务执行上述核心断言（健康检查/检索命中/混合 SQL 生效/记忆写入/跨会话召回/scope 隔离/证据留痕共 7 项），逐项输出 PASS/FAIL，明细写入 `evidence/demo_result.json`。本仓库 `evidence/` 目录是 2026-10-27 实测通过（7/7）的留档。

## 已知降级行为（非缺陷）

- 未接 LLM：回答变为"seekdb 混合检索直接结果摘要"，标注未接 LLM；记忆提炼暂停（无法自动沉淀），但记忆召回/面板/隔离均正常。
- PowerContext 停机：问答继续可用（无记忆召回，界面提示）；恢复后自动续上。
